# pizza-sales-mysql-analysis
This project is a SQL-based Pizza Sales Analysis project developed using MySQL. The main purpose of this project is to practice SQL by solving a series of real-world business questions using a pizza sales dataset.

The dataset contains four related tables: `orders`, `order_details`, `pizzas`, and `pizza_type`. These tables contain information about order dates and times, ordered pizza quantities, pizza prices and sizes, and pizza names, categories, and ingredients.

In this project, I solve different analytical questions step by step using SQL queries. Each question focuses on a specific business problem and requires different SQL concepts to obtain the correct result. For example, I calculate the total revenue generated from pizza sales, find the average number of pizzas ordered per day, and calculate the percentage contribution of each pizza category to the total revenue.

The project also demonstrates how multiple tables can be connected using `JOIN` operations and how aggregate functions such as `SUM()`, `AVG()`, and `COUNT()` can be used to analyze sales data. I also use `GROUP BY`, calculated columns, and subqueries to solve questions that require more detailed analysis.

### Tables Used

* `orders` – Contains order date and time information.
* `order_details` – Contains order details, pizza IDs, and quantities.
* `pizzas` – Contains pizza size, price, and pizza type information.
* `pizza_type` – Contains pizza names, categories, and ingredients.

### SQL Concepts Used

* SELECT statements
* INNER JOIN
* GROUP BY
* SUM()
* AVG()
* COUNT()
* Aggregate functions
* Subqueries
* Calculated columns
* Revenue and sales analysis

The goal of this project is to strengthen my practical SQL skills by solving business-oriented questions and understanding how relational databases can be used to extract meaningful insights from sales data.
